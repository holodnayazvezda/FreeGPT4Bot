# FreeGPT4Bot

Telegram-бот для диалогов с ИИ на aiogram 3. Поддерживает текст, фотографии и голосовые сообщения, выбор модели и статистику. В проекте есть интеграции с g4f, OpenAI и GigaChat, распознавание текста и речи.

## Подготовка и запуск

```sh
python -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python super_main.py
```

До запуска:

- Настройте `data/config.py`: список `TEST_TOKENS` (именно его использует `super_main.py`), администраторов и данные нужных ИИ-провайдеров.
- Запустите Redis; адрес задаётся в `REDIS_URL`, по умолчанию `localhost:6379`.
- Подготовьте каталог `data/databases/` и требуемые сервисами данные. Часть информации хранится в SQLite.

`handlers/` содержит обработчики Telegram, `utils/chatgpt/` — работу с моделями, `utils/recognizers/` — распознавание. Доступность моделей определяется используемыми внешними провайдерами.

`start.py` — дополнительная оболочка контроля соединения и перезапуска. Она рассчитывает на окружение `.venv`. В проекте также предусмотрено автоматическое обновление g4f при работе служебного потока.
